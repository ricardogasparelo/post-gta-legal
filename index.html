Post GTA

Personal publishing tool · Ferramenta pessoal de publicação

EN. Post GTA is a small personal desktop tool that sends short vertical videos that the owner already created to the owner's own social media accounts (Instagram, YouTube and TikTok). It uses each platform's official API. It is not offered to the public and does not collect data from other people.

PT. O Post GTA é uma pequena ferramenta pessoal de computador que envia vídeos verticais curtos, já criados pelo próprio dono, para as contas do próprio dono (Instagram, YouTube e TikTok), usando as APIs oficiais de cada plataforma. Não é oferecida ao público e não coleta dados de outras pessoas.
