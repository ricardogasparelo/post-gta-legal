Privacy Policy / Política de Privacidade

Last updated / Atualizado em: 19 Nov 2026

English

  • Who uses it. Post GTA is a personal tool used only by its owner. It does not collect, sell or share personal data of any other person.
  • What it stores. When the owner logs in with TikTok, Instagram or Google, the tool keeps the access token on the owner's own computer only, to upload the owner's own videos. It does not read followers, messages or any other account data.
  • Servers. There is no server and no database. Nothing is sent to third parties other than the official API of the platform the owner chose to post to.
  • Removal. The owner can revoke access at any time in the security settings of each platform and by deleting the local token file.
  • Contact. Instagram @cortessgta_vi.

Português

  • Quem usa. O Post GTA é uma ferramenta pessoal, usada só pelo dono. Não coleta, vende nem compartilha dados pessoais de outras pessoas.
  • O que guarda. Ao fazer login com TikTok, Instagram ou Google, a ferramenta guarda o token de acesso somente no computador do próprio dono, para enviar os próprios vídeos. Não lê seguidores, mensagens nem outros dados da conta.
  • Servidores. Não há servidor nem banco de dados. Nada é enviado a terceiros além da API oficial da plataforma escolhida.
  • Remoção. O dono pode revogar o acesso a qualquer momento nas configurações de segurança de cada plataforma e apagando o arquivo local do token.
  • Contato. Instagram @cortessgta_vi.
